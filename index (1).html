The problem

Accurate information, scattered everywhere

Scholarship and finance policy at Hull is correct — and split across PDFs, FAQ pages, and support pages that rarely use the words a student would.

Fragmented

Split across documents

Eligibility criteria, deadlines, and appeal rights live in different documents, phrased for policy — not for the student asking.

High stakes

Real consequences

A confident but ungrounded answer about award eligibility carries real financial consequences — not a domain for plausible guessing.

Under-studied

Rarely compared head-to-head

Applied RAG literature rarely compares retrieval architectures directly inside one high-stakes institutional deployment.

Architecture

Two components, one honest coupling

A classical ML router decides what to search; a RAG pipeline retrieves, expands context, and generates a cited answer. Their interaction is tested, not assumed safe.

Validation

Testing whether the improvement was real

A single high score isn't evidence. A tuning/held-out split, grid search, and paired significance test were run before anything got called a result.

NOT SIGNIFICANT

Grid search, 14-question held-out set

Best combined configuration scored numerically higher than baseline — but a paired t-test gave p = 0.146. With only 14 held-out questions, that gap isn't confirmed. Reported honestly, not rounded up.

t = 1.545 · combined 0.905 (±0.073) vs. baseline 0.702 (±0.034)
VALIDATED

Sample-size stability check

The same strategy family, validated on the full 50-question set across 3 independent trials, landed lower but far more stable — a ~6× reduction in variance.

0.857 citation accuracy · SD 0.012 · n = 50
Engineering

Bugs aggregate metrics didn't catch

Found only by testing individual adversarial queries, not by watching averages.

FIXED

Confidence-gated routing

A 19.9%-confidence classifier prediction was silently filtering out the correct retrieval candidate. Fix: routing only applies above a 0.3 confidence threshold.

FIXED

Citation window-matching

A correctly-cited neighbouring chunk was scored as hallucinated due to a labelling gap. Fix: every real chunk ID in a window is now exposed to the scoring function.
